2. ตรวจไฟล์ Excel ในเครื่อง

อ่านเฉพาะใน Browser · ไม่ส่งไฟล์ไป Server

กำลังตรวจสอบว่ามีข้อมูลฐานเดิมสำหรับเปรียบเทียบหรือไม่

กรุณาเลือก Worksheet, ปีดำเนินงาน และ Mapping ให้ตรงกับข้อมูลจริง โดยเฉพาะยอด AP ต้องเป็นยอดสะสม ไม่ใช่รายการจ่ายแต่ละครั้ง

ผลตรวจเบื้องต้น

รายการยอดที่เปลี่ยน (แสดงไม่เกิน 150 รายการ)

3. ตรวจยอดก่อนเผยแพร่
ไฟล์หนึ่งรอบต้องครบขอบเขตที่เลือก หากหาแปลงไม่ครบหรือยอดไม่ตรง ระบบจะหยุด
ยังไม่มีผลตรวจสอบ
ผลตรวจยอดและขอบเขต
รายการข้อมูลต้นทางข้อมูลที่อ่านได้ผลต่าง / ผลตรวจ
รายการเปลี่ยนแปลง
แปลง / ปีBOQ เดิม → ใหม่AP เดิม → ใหม่
ที่มาของข้อมูลระดับเซลล์
ยอดรวมที่ผ่านไม่ได้ยืนยันความหมายของข้อมูลแทนคนตรวจ งวดจ่ายที่ไม่มีข้อมูลยืนยันจะไม่ถูกเดาแบ่งจากยอดรายปี
