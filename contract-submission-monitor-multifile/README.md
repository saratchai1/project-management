# Contract Submission Monitor · Multi-file Project Hub

แอปใหม่แยกจาก `contract-submission-monitor/` และ `work-monitor-multifile/`

## เป้าหมาย

- ผู้ใช้สร้าง/เลือกโครงการเอง
- เพิ่มหรือลบ Excel หลายไฟล์ต่อโครงการได้
- Excel ถูกอ่านใน browser เท่านั้น ไม่ upload raw workbook ขึ้น server
- Dashboard rebuild ทันทีเมื่อเพิ่ม/ลบไฟล์
- ถ้าไฟล์ใหม่มี `ปีโครงการ + ปีที่ + รหัสแปลง` ซ้ำกับไฟล์เก่า ใช้ไฟล์ที่เพิ่มล่าสุด

## Logic การส่งงาน

สำหรับ section `ปีที่ X งวดที่ Y ROK-ผรม.` ระบบหา column `ผรม. ส่งงานวันที่` อัตโนมัติ

- เป็นวันที่จริง -> `ส่งแล้ว`
- ว่าง -> `ยังไม่ส่ง`
- มีคำว่า `ชะลอ` / `หยุด` -> `ชะลอ`
- มีคำว่า `ยุติ` -> `ยุติ`
- ข้อความอื่นที่ไม่ใช่วันที่ -> `ยังไม่ส่ง` และแจ้ง Data Quality
- ถ้าวันที่อยู่หลังวันที่ปัจจุบัน -> ยังถือว่า `ส่งแล้ว` แต่ติด Future-date warning
- ถ้ากลุ่มสัญญาระบุจำนวนงวด เช่น `3 งวด` งวดที่เกินจากนั้น -> `N/A` เว้นแต่ช่องนั้นมีวันที่จริง ซึ่งจะถือว่า `ส่งแล้ว` ตาม rule หลัก

## Privacy

รายชื่อโครงการ persist เฉพาะ metadata ใน `localStorage` ส่วน Excel และผล parse อยู่ในหน่วยความจำของแท็บปัจจุบันเท่านั้น และหายเมื่อ refresh/ปิดแท็บ
