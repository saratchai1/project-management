# Carbon Credit Token — Project Plan Gantt

Static browser Gantt for the workbook `[Carbon Credit] Token Project Plan_PW_v.1 (20260826).xlsx`.

## Data boundary
- Reads **only** the worksheet named `Project Plan`.
- Does not read any other worksheet.
- Does not import or reference the existing Progress / ERP / planting-project datasets in this repository.
- The selected Excel file is parsed locally in the browser and is not uploaded to GitHub.

Open `/carbon-token-gantt/` on GitHub Pages, choose the workbook, and the page will map Task / Start / End or Duration / Progress / Owner / Status columns automatically.
