# ROK Subcontractor Contract Control

Dashboard แยกสำหรับติดตามสัญญาปีที่ 3 ระหว่างเจ้าของโครงการ **STC/VSD**, ผู้รับเหมาหลัก **ROK** และผู้รับเหมาช่วง โดยไม่แก้ไข Dashboard เดิมใน repository

## ข้อมูลหลัก

- ระเบียนสัญญา 163 รายการ / 160 รหัสแปลง
- สัญญาปัจจุบัน 151 แปลง
- แปลงชะลอ 9 แปลง
- สัญญาเดิมที่ยกเลิก 3 รายการ และสัญญาทดแทน 3 รายการ
- มูลค่าสัญญาปัจจุบัน 10,060,532.17 บาท
- ผู้รับเหมาช่วง 42 ราย
- ผู้รับผิดชอบสัญญา 24 ราย
- เจ้าหน้าที่ประจำแปลง 25 ราย

## มุมมอง

1. ภาพรวม KPI และการกระจายมูลค่า
2. สายสัญญา STC/VSD → ROK → ผู้รับเหมาช่วง
3. โครงสร้างวงเงินล่วงหน้าและงวด 1–3
4. ทะเบียนสัญญาแบบค้นหา กรอง เรียง และ Export CSV
5. ข้อยกเว้น เช่น สัญญาทดแทน ไม่มี PR/WO วันสัญญาผิดปกติ และแปลงชะลอ

## ข้อจำกัดการตีความ

ยอดในหน้าโครงสร้างงวดเป็น **วงเงินตามสัญญา** ไม่ใช่ยอดจ่ายจริงจาก ERP หรือ bank clearing
